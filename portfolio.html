Paul's Bite

A food ordering platform I built from the database up — the kind of project that touches every layer: schema design, server logic, and the interface a customer actually orders from.

Customers browse a categorized menu, build a cart, and check out without needing an account — the kitchen gets notified by email the moment an order lands, and every order can be tracked with a unique code. Behind the scenes, an admin dashboard gives restaurant staff control over the whole operation.

  • Guest checkout with order tracking by phone number or code
  • Real-time kitchen email notifications on new orders
  • Admin dashboard — order management, menu & category CRUD, discount codes, revenue charts
  • Customer reviews on menu items
